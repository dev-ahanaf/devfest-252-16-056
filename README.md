## Overview
A client-side web application built for office staff to turn a collection of PDF files into a complete, verified, and correctly ordered Tender Document Package ready for submission.

## Tech Stack
- Frontend: Vite + Vanilla JavaScript
- PDF Processing: `pdf-lib` (pure client-side browser execution)
- Styling: Custom responsive CSS with Glassmorphism UI (Bangla / English bilingual support)
